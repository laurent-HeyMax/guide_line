## HeyMax Motion Guide

This private repository is the home for HeyMax logo, brand and motion guidelines. The runnable guide files will be added in a separate pull request. Until then, the current main branch contains this README only.

### Run the guide locally

1. Once the guide is available, open the branch containing it in GitHub and select **Code → Download ZIP**. You can also clone that branch if you have repository access.
2. Unzip the download and open Terminal in the folder containing `index.html`. Keep `index.html` and the `motion/` folder together so clips and posters load.
3. Start a local server:

   ```sh
   python3 -m http.server 4173 --bind 127.0.0.1
   ```

4. Open [Motion Guidelines](http://127.0.0.1:4173/#motion). In **The Lift**, choose **1X** for normal playback (default) or **1/2X** for half speed. Press Ctrl+C in Terminal when finished. The local address only works on your own computer.
